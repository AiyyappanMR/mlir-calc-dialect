# Calc Dialect Python Bindings

This directory contains the Python bindings for the `calc` MLIR dialect. 

These bindings allow you to construct, manipulate, parse, and compile `calc` dialect operations directly from Python, providing a higher-level, user-friendly interface for generating and analyzing MLIR IR programmatically.

## Directory Structure

* **`CalcModule.cpp`**: This is the core `nanobind` C++ extension source file. It bridges the Python runtime with the internal MLIR C++ structures by utilizing the stable C API (defined in `lib/CAPI/`). It exposes the `calc` dialect registration and pass pipelines to the Python environment.
* **`calc_mlir/`**: This is the actual Python package directory that will be installed and imported in your Python scripts.
  * `dialects/`: Contains the Python modules representing the dialect. This typically includes auto-generated Python classes (generated by `mlir-tblgen` during the build process) for each `calc` operation, providing an idiomatic, object-oriented Python API for IR construction.
  * `_mlir_libs/`: A designated directory that holds the compiled `.so` (or `.dylib` / `.pyd`) C++ extension binaries built from `CalcModule.cpp` and linked against the MLIR core.

## Usage Examples

For comprehensive examples of how to import, register, and use the `calc` dialect in Python, please refer to the test suite located in `test/python/`. 

Files such as `test/python/calc_python_binding_test.py` provide excellent, up-to-date starting points for understanding how to interact with the dialect's Python API.
